[Phase 2.2] Wrote `app/services/parsing.py`: `parse_quiz_excel(file) -> list[QuestionSchema] | ParseError`, using `openpyxl`. Validates per row: non-empty question text, non-empty + pairwise-distinct options, `correct_option` is exactly one of A/B/C/D (case-insensitive). Any row failure collects ALL of that row's failure reasons (not just the first) and ALL faulty rows across the file (not just the first bad row) — the function returns either the complete valid list or a `ParseError`, never a partial mix. Verified in `backend/tests/test_parsing.py` (4 tests): valid fixture asserts exact field values (not just count) for all 3 rows including a case-insensitive `"b"` → `"B"` normalization; the two required invalid fixtures assert exact row number + exact message string; a 4th test (`multiple_errors.xlsx`) proves two separate bad rows are both reported with their own distinct messages in one pass. — DoD verified.
